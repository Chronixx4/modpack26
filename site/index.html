Chronicle

Magie, Create, AE2 und neue Dimensionen – das Modpack für Chronixx und Freunde
Minecraft 1.21.1 NeoForge 21.1 Java 21 ~300 Mods Questbuch mit 1400+ Quests

Download

Neueste Version auf GitHub öffnen Alle Dateien (.mrpack, Client-ZIP, Server-ZIP)

Installation (Modrinth App)

  • Datei Chronicle-<Version>.mrpack herunterladen.
  • Modrinth App: + → Aus Datei importieren.
  • Mindestens 8 GB RAM zuweisen, Java 21.
  • Andere Launcher (Prism, CurseForge): die Client-ZIP nutzen.

Was steckt drin?

  • Magie: Ars Nouveau, Iron's Spells, Goety
  • Technik: Create mit vielen Addons, Mekanism, Draconic Evolution
  • Lager: Applied Energistics 2 und Refined Storage
  • Abenteuer: Twilight Forest, Aether, Cataclysm, viele Bosse und Strukturen
  • Chronicle-Kern: eigenes Endgame mit Fragmenten, Skilltree und Bossführer

Server

Die Server-ZIP enthält Start-Skripte, Java-Flags und eine Anleitung. Ports: 25565/TCP und 24454/UDP (Voice Chat).

Nur für Freunde. Einige Mods stammen von CurseForge, das Pack bitte nicht öffentlich weitergeben.
