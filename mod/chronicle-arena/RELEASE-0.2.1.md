# Chronicle Arena 0.2.1 – Menü-Korrektur

Die Gruppen-, Admin-, Begegnungs- und Schwierigkeitsmenüs werden jetzt nach dem Hintergrund-Unschärfeeffekt gezeichnet. Texte und Rahmen bleiben dadurch scharf. Der Hintergrund wird pro Frame nur einmal gerendert.

Enthält weiterhin alle Funktionen aus 0.2.0. Java 21, Minecraft 1.21.1 und NeoForge 21.1.x.

## Installation

Alte Arena-JAR entfernen und durch `chronicle-arena-0.2.1.jar` ersetzen, auf dem Server und auf allen Clients. Anschließend neu starten. Welt und Einstellungen bleiben erhalten.

## Prüfung

Java-21-Build und sechs automatisierte Tests erfolgreich. Render-Reihenfolge anhand der verwendeten NeoForge-Quellen geprüft. Keine Minecraft-Instanz gestartet; die visuelle Bestätigung im Modpack erfolgt im Spieltest.
