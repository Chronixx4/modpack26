# KeybindOverview Mod

Eine Minecraft Forge Mod für Version 1.21.1, die eine bessere Übersicht über Tastenbelegungen bietet.

## Features

- Die Übersicht ersetzt das Tastenbelegungs-Menü (Optionen -> Steuerung)
- Kategorisierte Darstellung aller Tastenbelegungen
- Mehrspaltiges Layout für bessere Übersicht
- Scrollbare Ansicht mit Mausrad-Unterstützung
- Drücke **ESC** oder **Backspace** um zu schließen

## Build

```bash
./gradlew build
```

Das fertige JAR befindet sich in `build/libs/`.

## Installation

Kopiere das JAR in deinen `.minecraft/mods` Ordner.
