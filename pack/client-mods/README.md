# Lokale Client-Mods

JARs in diesem Ordner kommen in `client-overrides/mods` der Modrinth-Datei und
in `mods` der Client-ZIP. Sie kommen nicht in die Server-ZIP.

## Keybind Overview 1.0.0

Eigene Mod aus Marvins Projekt `KeybindOverview`, aktueller Build vom 11.10.2026.
Minecraft 1.21.1, NeoForge ab 21.1.0, Java 21; Lizenz laut Mod-Metadaten: MIT.

SHA-256: `c002abca57202fd53672a51178bac93c803696e3dda25730fe40c8479cd090a7`

Ersetzt die Tastenbelegungsseite durch eine Tastatur- und Kategorienansicht.
Suche nach Aktion, Kategorie oder Taste (Strg+F), Filter fuer Mehrfachbelegungen
und unbelegte Aktionen, bis zu vier Spalten und einklappbare Kategorien.
Belegungen lassen sich direkt bearbeiten und speichern.

Aufruf: Optionen -> Steuerung -> Tastenbelegung; alternativ Taste K.
K ist auch der Standard fuer den Skilltree. Bei Bedarf unter Tastenbelegung
eine der beiden Aktionen auf eine andere Taste legen.
